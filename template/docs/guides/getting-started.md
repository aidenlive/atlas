# Getting started

Replace this guide with the real one. Its shape is the point: prerequisites,
numbered steps, and a way to verify the result.

## Prerequisites

- The Atlas CLI: `pip install atlas-standard`

## Steps

1. Clone the repository.
2. Install dependencies.
3. Run the checks.

## Verify

```bash
atlas check
```

A clean run means the repository meets the standard. Whether the code is any
good is a different question, and a reviewer's.
