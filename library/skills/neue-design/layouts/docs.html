Getting started

Install the stylesheet, set the theme attribute, and write inside the reading column. Nothing else is required.

Install

Two lines are the entire install. Tokens, layout primitives, and components arrive together; behaviour is a separate deferred script and every no-JS state is the finished state.

Tokens, not values

Every colour is a semantic token such as --color-surface or --color-outline-strong. If you find yourself typing a hex value, the system is missing a token — add it there rather than working around it.

The interactive-boundary rule.

Control perimeters use outline-strong; the plain outline hairline is decorative only. A text input drawn with outline looks correct and fails the non-text contrast requirement.

Dark theme

Both themes share identical token names; only values change. Set data-theme="dark" on the root, or wire any control with data-theme-toggle.
