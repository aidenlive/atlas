# library/skills

Agent skills: packaged capabilities, one directory per skill (`L-S1`..`L-S4`).

A skill travels as a unit — instructions (`SKILL.md`), metadata (`skill.yaml`),
and the assets it acts on — so a person can copy it into any project and an
agent can be pointed at it without further explanation.

| Skill | Capability |
|---|---|
| [`neue-design/`](neue-design/SKILL.md) | Apply Neue, the fleet's visual identity, to a web surface |

`index.yaml` is this class's machine index, generated by
`scripts/build_library.py` from the `skill.yaml` files (`L-A2`).

Routines that compose several skills reference them by directory; they never
inline a copy (`L-S3`, `L-A1`).
